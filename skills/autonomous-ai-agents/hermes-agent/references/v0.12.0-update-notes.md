# Hermes Agent v0.12.0 更新记录

> 更新日期: 2026-05-01
> 从 v0.11.0 (2026.4.23) 升级，319 commits

## 新功能

- Microsoft Teams 适配器（插件）
- Piper 本地 TTS（免费，无需API Key）
- 多图原生发送（Telegram/Discord/Slack/Mattermost/Signal/Email）
- TTS command-type provider（tts.providers.name 配置自定义TTS命令）
- Dashboard 增强（配置模型、--stop/--status）
- Curator 改进（最常用/最少用skill统计）
- /reload-skills 命令
- IRC 平台支持
- 平台插件化（12个集成点）
- MiniMax OAuth PKCE
- Vercel Sandbox 后端
- Kanban 工具
- TUI 帮助菜单（输入 ? 弹出）

## 重要修复

- DeepSeek v4 reasoning_content 重放丢失
- Kimi/Moonshot thinking 模式扩展
- Gateway 消息丢失（agent失败时不丢弃用户消息）
- config set YAML 列表类型被破坏
- execute_code RPC 并发冲突
- Gateway 认证（防止未授权注入）
- Ollama context_length 识别
- Gemma thinking 在 Gemini provider 上报错

## Patch 兼容性

v0.11.0 到 v0.12.0 的 patch 兼容情况：

| Patch | 结果 |
|-------|------|
| weixin-markdown-conversion | 无冲突，偏移12/25行自动适配 |
| dingtalk-proactive-send | 无冲突，偏移160行自动适配 |
| delegate-tool | 无冲突 |
| xiaomi_tts_tool | 独立文件不受影响 |

## 注意事项

- `patch` 命令需要单独安装（yum install -y patch）
- 平台插件化可能改变适配器加载方式，未来更新需额外检查
- tts.providers.name 可以替代自定义 xiaomi_tts_tool（待迁移）
